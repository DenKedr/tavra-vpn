# TAVRA Shield: границы первого движка

`crates/tavra-shield` — собственный движок принятия решений по DNS hostname. Компиляция создаёт неизменяемый набор правил, который можно разделять между потоками. Политика включает категории ads, trackers, malware и annoyances. Счётчики отражают только вызовы движка: allowed/blocked и блокировки по категориям; объём сэкономленных данных не вычисляется.

Поддерживаемый синтаксис: `||host^` блокирует имя и поддомены по границе DNS label; `@@||host^` разрешает их; `exact:host` блокирует только имя; `allow:host` разрешает только имя; hosts-строки `0.0.0.0 host`, `127.0.0.1 host`, `:: host`, `::1 host` создают точные блокировки. Пустые строки и комментарии `!`/`#` пропускаются. Имена нормализуются IDNA и lowercase; завершающая корневая точка допустима. Разрешение имеет приоритет над всеми категориями блокировки. При нескольких блокирующих категориях приоритет: malware, trackers, ads, annoyances.

Косметические правила, regex, URL/path, wildcards, произвольные ABP modifiers и неизвестный синтаксис возвращаются в отчёте компиляции с номером источника/строки и причиной. Они не активируются. Неподходящие имена, IP literals и одноуровневые имена также отклоняются; отсутствие public-suffix database означает, что администратор обязан проверять широкие многоуровневые суффиксы (например co.uk).

Лимиты входов и правил защищают память; превышение общего лимита отклоняет компиляцию целиком. Некорректный hostname не увеличивает счётчики решений. Нет загрузки внешних списков, установки CA, изменения системного DNS или обещания системной фильтрации. Нет удаления элементов страниц, фильтрации HTTPS, определения приложений, DNSSEC-validation или перехвата стороннего DoH. Подключение к VPN/native runtime, encrypted upstream, UI counters и постоянное хранение политики — отдельные интеграционные задачи.

## Локальный UDP harness

`LoopbackDns::bind(Arc<Engine>, timeout)` открывает только `127.0.0.1:0`. `serve_once` обрабатывает один пакет, блокировку отвечает NXDOMAIN, разрешённый запрос передаёт async callback, предоставленному вызывающей стороной. Callback должен уступать Tokio: синхронно блокирующий код нельзя прервать async timeout. Таймаут ограничен 5 секундами; нулевой запрещён. Ошибка/таймаут/ответ не к тому запросу возвращает SERVFAIL. Пакеты больше 4096 байт, повреждённые пакеты, DNS responses и multi-question запросы отбрасываются. Ответ upstream проверяется по размеру, ID, opcode, QR и вопросам.

Harness не включает TCP DNS, EDNS negotiation, кеш, rate limiting или production service loop; вызывающий код управляет жизненным циклом/отменой и upstream transport. Тесты используют только loopback UDP, без удалённых DNS-запросов. Это интеграционная граница, а не системный DNS-resolver.
